## 🔧 트러블슈팅

### 1. 한글이 깨져서 출력되는 문제

**증상**
```
?????? ????
��� ���
```

**원인**
- Python 파일의 인코딩이 UTF-8이 아닌 경우
- Windows 터미널의 기본 인코딩이 CP949(EUC-KR)로 설정된 경우

**해결 방법**

방법 1 - main.py 상단에 인코딩 선언 추가
```python
# -*- coding: utf-8 -*-
```

방법 2 - 터미널에서 인코딩 변경
```bash
chcp 65001
```

방법 3 - VSCode 우측 하단 인코딩을 UTF-8로 변경
```
VSCode 우측 하단 → UTF-8 클릭 → Save with Encoding → UTF-8 선택
```
